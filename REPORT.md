# Отчёт по лабораторной работе №4. Ансамбли и полносвязные сети

Задача: бинарная классификация кредитоспособности на `german.csv` (1000 строк, 20 признаков, целевая `Creditability`, положительный класс = 1, доля 70%).

## Данные и подготовка

- **Split:** стратифицированный 80/20 (`train_test_split`, `test_size=0.2`, `stratify=y`, `random_state=42`): 800 train / 200 test.
- **Пропуски:** отсутствуют (проверено, 0 NaN), импутация не нужна.
- **Категориальные признаки без порядка** (`Purpose`, `Sex_Marital_Status`, `Payment_Status_of_Previous_Credit`, `Most_valuable_available_asset`, `Concurrent_Credits`, `Type_of_apartment`, `Guarantors`): `OneHotEncoder(handle_unknown="ignore")`.
- **Остальные признаки** (числовые и порядковые коды): `StandardScaler`, fit только на train.
- **Собственные признаки:** `Log_Credit_Amount = log1p(Credit_Amount)`, `Amount_per_Month = Credit_Amount / Duration`, `Monthly_Burden = Amount_per_Month * Instalment_per_cent`. Считаются построчно, статистики test не используются.
- Предобработка и модель собраны в один `Pipeline`, поэтому утечки test в fit нет.

## Гипотезы и эксперименты

1. **Базовая линия** — логистическая регрессия: данные небольшие, зависимости во многом близки к линейным.
2. **Бэггинг** (Random Forest, Extra Trees): на 800 объектах глубокие деревья переобучаются, поэтому проверялось ограничение `max_depth` и `min_samples_leaf`.
3. **Бустинг** (AdaBoost, GradientBoosting, HistGradientBoosting): мелкие деревья (`max_depth=2`), малый `learning_rate`, `subsample=0.8` как регуляризация.
4. **Полносвязная сеть** `MLPClassifier(32,16)` с L2 и early stopping: проверка, даёт ли нейросеть выигрыш на малой табличной выборке.
5. **Soft Voting RF + GB + LR:** гипотеза, что модели с разной природой ошибок (бэггинг, бустинг, линейная) при усреднении вероятностей дают более устойчивый результат.

Гиперпараметры подбирались вручную небольшим числом вариантов; решения принимались по CV на train, а не по test.

## Метрики

Критерий выбора модели: **средний ROC-AUC на 5-fold стратифицированной CV только по train**. Порог для бинарных предсказаний: 0.5.

## Выбранная модель

**Soft Voting** из Random Forest (500 деревьев, `max_depth=8`, `min_samples_leaf=3`), Gradient Boosting (150 деревьев, `max_depth=2`, `learning_rate=0.05`, `subsample=0.8`) и логистической регрессии (`C=0.3`) с равными весами. Выбрана, потому что у неё наибольший CV ROC-AUC на train (0.7917). Финальные метрики на test: ROC-AUC 0.8444, accuracy 0.800, precision 0.8165, recall 0.9214, F1 0.8658.

## Выводы и ограничения

- Усреднение разнородных моделей дало небольшой, но стабильный прирост по CV (+0.006…0.01 к лучшим одиночным моделям).
- Ограничение глубины деревьев и малый `max_depth` у бустинга помогли; AdaBoost и MLP на 800 объектах оказались слабее.
- Разница между моделями на CV мала (порядка 0.01) и сопоставима с разбросом по фолдам, поэтому выбор победителя не бесспорен.
- **Ограничение:** test-выборка из 200 объектов даёт шумную оценку. ROC-AUC на test (0.84) заметно выше CV на train (0.79), и даже простая логистическая регрессия получила 0.843. Скорее всего, этот split оказался «лёгким», а реальное качество ближе к ~0.79–0.80.
- Порог 0.5 при дисбалансе 70/30 даёт высокий recall класса 1 и низкую специфичность; для задачи кредитного риска порог стоило бы подбирать под стоимость ошибок.
- Гиперпараметры подбирались вручную, без полного перебора.

## Воспроизводимость

- Random seed: `42` (split, все модели, CV).
- Split: стратифицированный 80/20, как описано выше.
- Запуск: `python run_experiments.py` из корня репозитория. Скрипт повторяет все эксперименты, выбирает модель по CV на train, вызывает `run_ensemble_experiment` и перезаписывает `experiment_results.json`. Время на CPU около 20 секунд.
- Версия scikit-learn: 1.9.1.
